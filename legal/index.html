Privacy Policy

Last Updated: 10th September 2026

Crumb is a Discord bot operated by Pxsl. This Privacy Policy explains what information Crumb accesses, what information is stored, why it is used, and how data is handled when you use Crumb.

Crumb is designed to collect and store only the information reasonably required for its features to function.

Information We Store

Depending on which Crumb features are enabled or used in a server, Crumb may store the following information:

  • Discord server (guild) IDs
  • Discord channel IDs
  • Discord role IDs
  • Discord message IDs where required for bot configuration
  • Discord user IDs where required for features such as moderation, verification, security whitelists, reminders, and giveaways
  • Server configuration and feature settings
  • Moderation warnings, including the warned user's Discord ID, the moderator or bot responsible, the warning reason, and timestamp
  • Reminder information, including the user's Discord ID, server/channel IDs where applicable, the reminder message, and the scheduled reminder time
  • Giveaway entry information, including the Discord IDs of users who enter a giveaway
  • Verification information, including a temporary Discord user ID, CAPTCHA answer, attempt count, and expiry time while verification is in progress
  • Automod configuration, blocked words, and whitelist entries for users, roles, and channels
  • Server configuration for join, leave, boost, logging, security, verification, automod, honeypot, and other enabled features

Server Backups

If the server backup feature is enabled or a backup is created, Crumb may store a JSON representation of parts of the server's configuration.

Backups can contain information such as server IDs, server names, channel IDs and settings, role IDs and settings, permission configurations, and Discord user IDs where a permission overwrite specifically applies to a member.

Server backups are stored as files on the system running Crumb. They are not encrypted by Crumb. Automatic backups are subject to the retention setting configured for that server, while manually created backups may remain until they are deleted.

Message Content

Crumb may process Discord message content when required for features such as automod, spam detection, link and invite filtering, blocked-word filtering, and message logging.

Message content used by automod is processed to determine whether a message violates the server's configured rules. Messages detected by automod may also have their content included in an automod log sent to the server's configured logging channel.

Crumb does not intentionally maintain a general database of all messages sent through Discord. Message content processed for these features is not stored in Crumb's databases unless another Crumb feature specifically stores information derived from it.

Once information has been sent to a Discord channel, its retention is controlled by Discord and the server's own settings. Crumb does not control how long Discord retains those messages.

Temporary Data

Some information is held temporarily in memory while Crumb is performing a feature. This can include Discord member information, message content, voice state information, audit log information, and recent messages used for spam detection.

Temporary in-memory information is not intentionally written to Crumb's databases unless a feature specifically requires it to be stored.

Verification Data

When server verification is enabled, Crumb temporarily stores the Discord user ID of a person completing verification along with a generated CAPTCHA answer, the number of attempts, and an expiry time.

CAPTCHA information is intended to expire after five minutes and is removed when verification is completed or the CAPTCHA is otherwise invalidated. CAPTCHA information may remain in the database until Crumb next processes the relevant verification record.

How We Use Data

Information handled by Crumb is used to provide and operate the features requested by Discord server administrators and users.

  • Moderation and server management
  • Automod and security features
  • Server configuration
  • Verification
  • Reminders
  • Giveaways
  • Server backups
  • Server logging
  • Join, leave, and boost messages
  • Other functionality provided by Crumb

Information We Do Not Intentionally Request

Crumb does not intentionally request or require information such as passwords, payment card details, Discord account passwords, or precise physical location information in order to use the bot.

However, users and server administrators can enter their own text into features such as reminders, warning reasons, blocked-word lists, giveaway information, and message configurations. Users should therefore avoid entering unnecessary personal or sensitive information into those fields.

Data Retention

Different types of data are retained for different periods depending on the feature that created them.

For example, reminders are retained until they are cancelled, cleared, or processed. Moderation warnings remain until they are removed by an appropriate moderation action. Giveaway entries may remain in Crumb's database after a giveaway has ended or been cancelled. Server backups remain according to the configured backup retention settings, while manually created backups may remain until manually deleted.

Configuration data may remain while the relevant Crumb feature is configured for a server. Disabling a feature does not necessarily delete all previously stored configuration or historical data associated with that feature.

Data Sharing

Crumb does not sell or rent stored bot data.

Information may be sent to Discord as part of normal bot functionality. For example, moderation and automod logs may be sent to channels configured by server administrators, and giveaway winners may be publicly announced in the relevant Discord server.

Discord operates its own services and privacy practices. Information sent to Discord is subject to Discord's own policies and systems.

Crumb may also use third-party services for parts of its website, such as Google Analytics, as described below.

Website Analytics

The Crumb website uses Google Analytics to understand website usage and improve the site. Google Analytics is optional and is not loaded unless you explicitly accept analytics through the consent banner.

If you accept analytics, Google Analytics may collect information such as page views, approximate usage information, browser and device information, and interactions with the website. Google Analytics may use cookies and similar technologies.

Your analytics preference is stored locally in your browser using local storage. This preference is separate from data stored by the Crumb Discord bot.

If you decline analytics, the Google Analytics script is not loaded by the Crumb website.

You can change your analytics preference at any time using the Analytics Settings button on this page.

You can read Google's privacy policy here: Google Privacy Policy

Data Deletion

Crumb does not currently provide a single command that automatically deletes every piece of data associated with a server or Discord user.

Where a feature provides its own deletion mechanism, users or server administrators can use that mechanism. For example, reminders can be cancelled or cleared, moderation warnings can be removed individually, automod whitelist entries can be removed, honeypot configuration can be removed, and server backups can be deleted.

If you need assistance removing stored data that cannot be deleted through an available command, you can contact the developers through the Crumb community server.

Removing Crumb from a Discord server does not by itself guarantee that all previously stored data is immediately deleted. Stored data may need to be removed separately.

Data Security

Crumb stores persistent bot data in local databases and files on the system running the bot. Reasonable measures are taken to protect the systems running Crumb, but no method of electronic storage can be guaranteed to be completely secure.

Crumb's server backup files are currently stored as JSON and are not encrypted by the bot.

Children's Privacy

Crumb is a Discord bot and is not specifically directed at collecting personal information from children. Crumb does not intentionally request information such as real names, addresses, or passwords from users.

Users should follow Discord's own age requirements and terms when using Discord and Crumb.

Changes To This Policy

This Privacy Policy may be updated when Crumb's features, data handling, or services change. The "Last Updated" date at the top of this policy will be changed when material updates are made.

Contact

If you have questions about this Privacy Policy or want to request assistance with stored data, contact the Crumb developers through the community server linked below.
